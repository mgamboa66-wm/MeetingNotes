# MeetingNotes

MeetingNotes busca ayudar a crear notas de conversaciones de reuniones a partir del audio de la computadora.

## Estado

El proyecto está en etapa inicial. Todavía no se han definido la plataforma, el método de captura de audio, la transcripción ni el stack técnico.

## Decisiones pendientes

- Sistemas operativos y plataformas compatibles.
- Cómo capturar el audio y solicitar los permisos necesarios.
- Cómo transcribir y dónde procesar el audio.
- Cómo guardar y proteger el audio y las notas.

## Plan

El plan de implementación se añadirá cuando esté aprobado.
